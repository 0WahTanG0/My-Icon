# Which apps get an icon in the pack.
#
#   [Category]            starts a category (used for drawable.xml / icon picker)
#   com.example.app       every Lawnicons appfilter entry of this package
#   prefix:com.samsung.   every Lawnicons entry whose package starts with it
#   drawable:name         include a Lawnicons drawable as is (picker only)
#   map:pkg/activity=drawable   own appfilter entry (drawable from Lawnicons or pack/glyphs)
#
# tools/vendor_lawnicons.py turns this into third_party/lawnicons/.
